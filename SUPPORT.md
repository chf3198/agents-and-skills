# Support

## Getting Help

- **Bug reports:** Open a [GitHub issue](https://github.com/chf3198/agents-and-skills/issues) with the `type:bug` label
- **Feature requests:** Open a [GitHub issue](https://github.com/chf3198/agents-and-skills/issues) with the `type:story` label
- **Questions:** Open a [GitHub Discussion](https://github.com/chf3198/agents-and-skills/discussions) in the Q&A category

## Before Opening an Issue

1. Search existing issues — your question may already be answered
2. Run `npm run preflight` and include the output in your report
3. Include your Node.js version (`node --version`) and OS

## Response Time

This is a community-maintained project. Response times are best-effort.
Critical security issues are prioritized — see [SECURITY.md](SECURITY.md).
